# **Shayarific** - The Magic of Shayari at Your Fingertips ✨

Welcome to **Shayarific**, an AI-powered Shayari generator that transforms your thoughts, feelings, and emotions into beautiful poetry. Whether you're seeking a romantic couplet, a reflective verse, or a soulful poem, **Shayarific** makes it easier than ever to create the perfect Shayari, with just a few words.

---

## **Features** 🚀

- **AI-Powered Shayari Generation**: Leveraging the power of machine learning, Shayarific generates original and creative Shayari based on your input.
- **Customizable Poem Length**: Choose how many lines or words you want in your generated poetry.
- **Intuitive User Interface**: Simple and interactive interface to provide your input and receive a personalized poem instantly.
- **Seamless Integration**: Easy to deploy and run using **Streamlit** for smooth user experience.

---

## **How It Works** 🤖

1. **Input Your Seed Text**: Enter the starting phrase or word of your choice to inspire the poem.
2. **Select Length**: Choose how long you want the generated Shayari to be – from a short couplet to a full-fledged poem.
3. **Click Generate**: Let Shayarific work its magic! The app uses AI to generate a poem based on your seed text.
4. **Enjoy Your Shayari**: Instantly view your personalized Shayari with proper formatting and line breaks.

---

## **Technologies Used** 💻

- **TensorFlow**: For building and training the machine learning model that generates poetic verses.
- **Streamlit**: For creating an interactive web application interface that allows users to input text and view generated poems in real time.
- **Pickle**: To save and load the trained tokenizer and other model parameters.
- **NumPy**: For efficient mathematical operations required during the prediction phase.

## **How to Use** 🛠️

1. **Clone the Repository**:  
   ```bash
   https://github.com/AleySid193/Shayarific.git
   ```

2. **Install Dependencies**:  
   Install the required Python packages using pip:
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the App**:  
   Launch the Streamlit app:
   ```bash
   streamlit run app.py
   ```

4. **Generate Shayari**:  
   Once the app is running, go to your browser, input a seed text, select the length of the poem, and hit **Generate Poetry**!
